🚚 Raising a transfer request

Move bales from one store to another — with the bale numbers you want sent.
For office staff · every active user may raise one · the dispatcher at the source logs what actually leaves, the receiver confirms what arrives · an admin approves each stage
THE ONE RULE
You order by bale NUMBER. The bot never picks bales for you.
Your numbers ride the request as 📌 Ordered guidance. The dispatcher ticks the bales that physically leave; if one of yours is gone, the card says so and a person chooses the replacement — never the bot (business rule §2).
Three ways to raise it

A · Type the bale numbers — one line in the chat. Fastest when you have the numbers.

B · Tap through — 🔁 Move Stock → 🚚 Transfer Stock. Store → design → shade → how many → where to.

C · Say it in words — "Transfer package 5801 to Kano". The bot reads it and lands you on the same screens as A.

Before you start
  • Have the printed bale numbers from the packing list.
  • All bales of one request must sit in ONE store. Two stores = two requests.
  • Know the destination store's name as the bot spells it (Kano office, IDUMOTA, Lagos).
  • One request per load: if the same load is already open, the bot shows it instead of making a twin.

Method A — type the bale numbers (fastest)

One message. Numbers separated by commas or spaces, then to and the destination store. Up to 50 numbers. The bot finds every bale on the shelf, groups them by design and shade, and pins your numbers to the order.

1

Any of these work. The word Transfer (or Move / Send) at the front tells the bot what you mean; the numbers are the bales; everything after the last to is the destination.
You do not type the source. The bot reads where the bales sit. If they sit in two stores it loads the first store's bales and lists the others as in IDUMOTA, not Lagos — start a separate transfer.

The twin guard
If the same load (same route, same designs, shades and quantities) is already open, Send does not create a second one. You get the existing reference instead; only an admin may Send anyway, and that copy is marked ⧉.
Tapping Send twice on a slow network sends ONE request: the bot recognises its own repeat and shows was already sent.

Quick answers
  • A bale I typed is not on the card — read its reason line: sold, in transit, in another store, or not on record. Fix the number or start a separate transfer for the other store.
  • The dispatcher sent different bales — allowed. Physical truth wins; the confirm screen told him in words which ordered number he replaced.
  • Only some bales arrived — the receiver ticks the ones that came (📦 Only some arrived); the rest stay on the road and the row reads 6/10B until the last bale.
  • I want to cancel — there is no cancel after Send. The dispatcher taps ❌ Decline, which returns the bales to the source.
