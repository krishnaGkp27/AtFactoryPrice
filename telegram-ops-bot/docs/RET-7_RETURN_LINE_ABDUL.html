How to type a return

From today the bot takes a return in ONE way only. Type the word Return, then the numbers. Nothing else.
Type this:
Return 631/1+2+3, 614
Use your own bale numbers. This line returns thans 1, 2 and 3 of bale 631, and all of bale 614.
The five rules
Returnthe word Return, then the bale numbers
631/1one than
631/1+2+3several thans of one bale
614a whole bale
,a comma between bales
Numbers only. No customer name, no store, no other word.
Who is the customer? Which store?

“The bot takes the buyer and the store from the sale record.”

You do not type the customer. You do not type the store. The return card shows them to you. Check them there.

Capital letters and extra spaces do not matter.

Do not type

Words around the numbers. These are your lines from 20-Nov. The bot does not read them now:

  • Return 631/1+2+3+4+5,614/1 to Idumota ✗
  • Return package 631/1+2+3+4+5,614/1 to Idumota ✗
  • Return package from soldier madam 631/1+2+3+4+5,614/1 to Idumota ✗

No to Idumota. No package. No customer name.

For each of them the bot sends this card, and nothing else happens. Type the line again, the one way.

↩️ Return — type it one way only Return 631/1+2+3, 614 • the word Return, then the bale numbers • one than: 631/1 • several thans of one bale: 631/1+2+3 • a whole bale: 614 • a comma between bales Numbers only.
